## Розподіл виводів

### Порт A

| Вивід | Режим     | Призначення        | Примітка            |
|-------|-----------|--------------------|---------------------|
| PA0   | OUT       | <...>              |                     |
| PA1   | OUT       | LED blue           | pull-down           |
| PA2   | AF1       | UART2 TX           |                     |
| PA3   | AF1       | UART2 RX           |                     |
| PA4   | IN        | Кнопка «вправо»    | pull-up             |
| PA5   | IN        | Кнопка «вліво»     | pull-up             |
| PA6   | IN        | Кнопка «вгору»     | pull-up             |
| PA7   | IN        | Кнопка «вниз»      | pull-up             |
| PA8   | OUT       | LCD R/W            |                     |
| PA9   | AF1       | UART1 TX           |                     |
| PA10  | AF1       | UART1 RX           | pull-up             |
| PA11  | OUT       | Direct Rx/Tx       | напрямок RS-485 (?) |
| PA12  | OUT       | LCD RS             |                     |
| PA13  | SWD       | SWDIO              | не перевизначати    |
| PA14  | SWD       | SWCLK              | не перевизначати    |
| PA15  | OUT       | LCD E              |                     |

### Порт B

| Вивід    | Режим | Призначення            | Примітка |
|----------|-------|------------------------|----------|
| PB0      | OUT   | Підсвітка LCD On/Off   |          |
| PB1, PB2 | OUT   | LCD DB0, DB1           |          |
| PB3–PB6  | OUT   | StepMotor 1–4 (фази)   |          |
| PB7–PB9  | IN    | KEY1–KEY3 (сканер)     | pull-up  |
| PB10–PB15| OUT   | LCD DB2–DB7            |          |

> Налаштування виводів зібрано в таблиці `pin_table[]` у файлі `gpio_init.c`.
> Якщо змінюєте розводку, редагуйте цю таблицю і цей розділ разом.

## Структура проєкту

```
<project>/
├── Core/
│   ├── Inc/
│   │   └── General_Definition.h   # загальні визначення
│   └── Src/
│       ├── main.c
│       ├── gpio_init.c            # таблиця та ініціалізація виводів
│       ├── lcd.c                  # драйвер LCD
│       ├── stepper.c              # керування кроковим двигуном
│       ├── keys.c                 # опитування кнопок
│       └── uart.c                 # обмін через UART
├── Drivers/                       # CMSIS / HAL / LL
├── hardware/                      # схема, PCB, BOM
├── docs/                          # документація, зображення
└── README.md
```
